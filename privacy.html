Privacy policy

Last updated: 12 October 2026

Who this covers

Unmade is a documentary channel (@unmadedocs). It uses a private publishing tool, the "Unmade publisher", to upload and manage videos on its own YouTube channel. The tool is used only by the channel's owner. No one else signs in to it, and it never accesses anyone else's Google account or data.

What the tool accesses, and why

The tool uses YouTube API Services. With the owner's permission, given through Google's sign-in, it accesses the Unmade YouTube channel only, in order to:

  • upload the channel's own videos and set their titles, descriptions, thumbnails, captions, playlists and publish times (YouTube scopes youtube.upload, youtube and youtube.force-ssl);
  • read the channel's own YouTube Analytics reports (views, watch time, traffic sources) to learn which films work (scope yt-analytics.readonly).

How the data is kept

  • The sign-in token is stored as an encrypted secret in the tool's private environment. It is never published or shared.
  • Channel statistics are kept in a private repository and used only to plan and improve the channel's own videos.
  • Data from Google APIs is not sold, not shared with third parties, not used for advertising and not used by the channel to train AI models.

Unmade's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

By using YouTube you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access given to the tool can be removed at any time on the Google account connections page.

Visitors to this site

This site sets no cookies and runs no analytics or tracking. It is hosted on GitHub Pages, which may log visitors' IP addresses for security, as described in the GitHub Privacy Statement.

Contact

Questions about this policy: write to the channel through the contact details on its YouTube About page.
