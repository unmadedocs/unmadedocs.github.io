Sign in to YouTube

Renews the publisher's YouTube login. Everything happens in this browser: the page talks only to Google, and nothing is sent to or stored on this site.

0The app's ID (first time on this browser only)

The values of YT_CLIENT_ID and YT_CLIENT_SECRET from the environment settings (the Google Cloud "Desktop app" client of the Unmade publisher).

Saved on this browser.

1Sign in

Opens Google in a new tab. Pick the Google account that owns the channel, then the Unmade channel, and allow all the boxes. If Google says the app isn't verified: Advanced → Go to Unmade publisher.

Open the Google sign-in

2Paste the link

Google ends on a page that won't load ("This site can't be reached", an address starting with http://127.0.0.1:8765/?). That is expected. Copy that whole address from the address bar and paste it here.

3Save it

claude.ai/code → the environment pe-production → Environment variables → replace the YT_REFRESH_TOKEN=… line with this one and save. Do the same in any other environment that has the line. Don't paste it into a chat. Then close this tab: the page forgets the login when it closes.
